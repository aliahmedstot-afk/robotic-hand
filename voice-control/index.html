Not connected

Talk to your laptop.

Speak naturally. The page recognizes your words and sends approved actions to the small companion app running on your Windows laptop.

Connect your laptop

Run voice_assistant.py on your laptop first. It will show a one-time pairing code.

The companion listens only on your own laptop (127.0.0.1).

Voice command

Press the microphone and speak
Waiting for microphone permission

Try saying

“Open Notepad”Launch an approved app
“Open Calculator”Launch Calculator
“Open File Explorer”Open your files
“Volume up” / “Volume down”Adjust system volume
“Switch window”Move to another open window
“Show desktop”Minimize windows
“Type hello there”Type dictated text into the focused app
“Scroll down” / “Scroll up”Scroll the active window
“Search for space facts”Open a web search

Safety: this first version uses a limited list of commands. It does not delete files, run arbitrary terminal commands, install software, or change security settings. Check the recognized words before allowing an action. Use the microphone only when you intend to control the laptop.

Speech recognition works best in current Chrome or Edge. Keep the companion running while using this page.
