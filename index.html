Bluetooth connection

This page expects a nearby BLE device named RobotArm and the service/characteristic UUIDs configured in the page.

Web Bluetooth requires HTTPS and a supported browser. The five values are sent in this order: base rotation (0–360°), shoulder, elbow, wrist, gripper. A full 360° physical turn requires a base mechanism designed for continuous rotation; an ordinary 180° servo cannot do a full turn.
